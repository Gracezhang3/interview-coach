Walk me through a project you built. So the project was a real time speech analysis tool. The front end captured microphone audio in the browser using the Web Audio API and computed loudness and pitch every fifty milliseconds. The transcript came from a Whisper model running on a small Python server. The hardest part was latency. Whisper large took about eight seconds per utterance on a laptop, so we switched to the base model and chunked the audio, which brought it down to under one second with only a small drop in accuracy.
